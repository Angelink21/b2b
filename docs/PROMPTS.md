# Промпты по этапам

Как пользоваться: открой новый чат Cursor, включи нужный режим, скажи `Выполни ЭТАП N из @docs/PROMPTS.md` или вставь блок целиком.
Правила (`AGENTS.md`, `.cursor/rules`) подхватываются сами. Каждый этап заканчивается отчётом и остановкой.

| Этап | Режим | Результат |
|---|---|---|
| 0 | Plan | `docs/PLAN.md`: архитектура, версии, решения, вопросы |
| 1 | Agent | каркас, токены, шрифты, темы, i18n, оболочка, CI |
| 2 | Plan → Agent | конвейер CSV → JSON, API каталога, тесты |
| 3 | Agent | UI-кит и страница `_styleguide` |
| 4 | Plan → Agent | главная: линейка, секции |
| 5 | Agent | каталог, категории, карточка модели |
| 6 | Agent | сравнение моделей, datasheet |
| 7 | Plan → Agent | форма КП и отправка заявок |
| 8 | Agent | слой движения |
| 9 | Agent | SEO, OG-картинки, структурированные данные |
| 10 | Agent | качество: a11y, скорость, безопасность |
| 11 | Agent | деплой и передача |
| 12 | Agent | фото и CMS (когда будут фото) |

## ЭТАП 8. Слой движения (Agent)

Уровень задаётся `MOTION_LEVEL` в `src/config/motion.ts`. По умолчанию `expressive`; чтобы вернуться к строгому брифу (одна анимация загрузки), поставь `signature`.

```text
Контекст: @.cursor/rules/60-motion.mdc, раздел Motion в @docs/DESIGN.md, готовые страницы этапов 4–6.
Цель: сайт ощущается дорогим и точным за счёт движения, которое объясняет интерфейс, а не украшает его.

Реализуй (каждая анимация с комментарием `// motion: ...`):
1. Загрузка главной (signature, играет один раз за сессию, с try/catch на хранилище): машины по очереди встают на линию пола (stagger 60ms, translateY 12→0 + opacity,
   ease-emphasized, 420ms), затем шкала прочерчивается (scaleX 0→1, 500ms), ручки пружиной «ловят» стартовый диапазон. Суммарно ≤ 1.4s. До гидратации SVG уже виден.
2. Драг ручек (expressive): машины в диапазоне приподнимаются на 8px и становятся контрастными, остальные гаснут; число моделей меняет цифры вертикальным «роллом»;
   ручки магнитятся к анкерам визуально (клавиатура и aria не меняются).
3. Hover/focus на машине (expressive): подпись с кг и габаритами, шкала подсвечивает позицию; то же по focus-visible.
4. Список → карточка (expressive): View Transitions (React 19.3): название и силуэт перелетают на своё место; без поддержки браузера работает без анимации.

6. Таблица (expressive): при фильтрации строки перестраиваются layout-анимацией, анимируются только первые 30 строк.
7. Scroll-driven (expressive): вертикальная размерная линия вытягивается вдоль блока «Для кого» (CSS animation-timeline: view(), @supports; без поддержки статична).
8. Мелочи (expressive): нажатие кнопки (scale .98, 100ms), стрелка → сдвигается на 4px, смена темы 200ms только для background/color/border, галочка успеха прочерчивается.

Ограничения: только transform, opacity, stroke-dashoffset, clip-path; без сдвигов раскладки (CLS 0); при prefers-reduced-motion ничего не двигается.
Проверка: pnpm verify · pnpm e2e (включая reducedMotion: 'reduce') · Lighthouse mobile: Performance ≥ 90, CLS 0 · запись экрана или покадровые скриншоты сцены загрузки.
```
