# Fagor Industrial: «Лінійка»

Каталог как линейка: вся номенклатура на одной линии пола, в одном масштабе, под шкалой загрузки (кг). Шкала фильтрует каталог и ведёт в форму КП.

## Принципы
1. Один главный объект на экране: линейка. Всё остальное тихое.
2. Красный только для действий (кнопки КП). Выбор, диапазон и активные состояния рисуются чернилами.
3. Структура несёт данные: строки и таблицы вместо одинаковых карточек.
4. Масштаб честный: силуэты строятся из реальных габаритов (мм) каталога.
5. Движение одно: при загрузке диапазон «ловит» стартовые значения. Остальное только в ответ на действие. `prefers-reduced-motion` отключает всё.

## Токены
| Токен | Light | Dark | Роль |
|---|---|---|---|
| `--bg` | #F3F5F7 | #0E141C | фон страницы |
| `--floor` | #E3E7EB | #17202B | пол сцены, форма КП |
| `--surf` | #FFFFFF | #131B25 | поля, корпус машины |
| `--line` | #C5CCD4 | #2B3745 | разделители |
| `--ink` | #0F1B2D | #E9EEF3 | текст, диапазон, фокус |
| `--steel` | #556171 | #9AA7B5 | вторичный текст (≥4.5:1) |
| `--red` / `--red-h` | #C9331C / #B02A16 | те же | только кнопки-действия, белый текст 5.3:1 |

Типографика: Spectral 300 (заголовки, числа-сводки), Source Sans 3 400/500/600 (интерфейс, таблицы, `tabular-nums`). Только шрифты с кириллицей. H1 `clamp(34px,5.4vw,64px)`, H2 `clamp(26px,3.4vw,40px)`, H3 22/400, текст 17/1.55, подписи 15.
Отступы: 4 · 8 · 16 · 24 · 48 · 96. Радиусы: кнопки и поля 6px, чипы 20px, таблицы и строки 0. Тени: нет, глубина = смена фона. Контейнер 1200px, поля `clamp(16px, 4vw, 32px)`, сетка 12 колонок с gap 24px (32px от 1024px).

## Компоненты
- **Линейка (hero).** Машины стоят на общей линии, масштаб единый. Вне диапазона opacity .32. Шкала нелинейна: анкеры = ёмкости машин линейки, между ними интерполяция, поэтому ручки стоят ровно под машинами. Два нативных `input[type=range]` (доступны с клавиатуры), полоса диапазона `--ink`.
- **Кнопка.** Высота 44px (малая 36), 16/500. Primary красная, secondary с рамкой 1.5px `--ink`. Фокус: контур 3px `--ink`.
- **Строка.** Сетка 5/7/auto, разделитель 1px. Заголовок строки Spectral 22, hover подчёркивает.
- **Чип-фильтр.** Нажатое состояние `aria-pressed`, заливка `--ink`.
- **Таблица.** Заголовки-кнопки с `aria-sort`, числа не переносятся, горизонтальный скролл на узких экранах, показ по 60 строк.
- **Карточка модели.** Слева чертёж (силуэт и размерные линии из мм), справа список спецификаций из непустых полей и красная кнопка «Отримати КП на цю модель» (подставляет модель в форму).
- **Форма КП.** Метка над полем, обязательные: имя и контакт. Ошибка: текст, рамка 3px и полоса слева, а не только цвет. Успех: блок `role=status` с фокусом.

## Поведение и контент
- Языки uk/en: переключатель в шапке, словарь `L`. Данные каталога остаются украинскими, типы и нагрев переведены. Украинский на ~15–20% длиннее английского, макеты рассчитаны с запасом.
- Темы: `data-theme` на `<html>`, обе проработаны, красный общий.
- Роутинг по хэшу: `#home`, `#catalog`, `#m<индекс>`, `#quote`.
- Фото: отсутствуют, силуэты временные. Подключать вырезки в единый ракурс (фронт), тогда масштаб линейки останется честным.
- Доступность: skip-link, `aria-live` для счётчика моделей, контраст ≥4.5:1, цель касания ≥44px.

## Не входит в прототип
Кейсы (нужны реальные истории), сравнение моделей, фото, отправка формы.

## Motion (токены для продакшена)
| Токен | Значение | Применение |
|---|---|---|
| `--dur-fast` | 120ms | нажатие, hover |
| `--dur-base` | 200ms | смена темы, фокус, подсветки |
| `--dur-slow` | 400ms | появление машин, переходы |
| `--dur-signature` | 1100ms | сцена загрузки главной |
| `--ease-standard` | cubic-bezier(.2,0,0,1) | всё обычное |
| `--ease-emphasized` | cubic-bezier(.16,1,.3,1) | появление, «приземление» |

Допустимые свойства: `transform`, `opacity`, `stroke-dashoffset`, `clip-path`. Пружины без отскока. Уровень задаёт `MOTION_LEVEL`: `signature` или `expressive`. При `prefers-reduced-motion` ничего не двигается.

## Отличия продакшена от прототипа
1. В блоке «Для кого» нет счётчиков моделей: почти все модели подходят всем отраслям (см. DATA_CONTRACT).
2. Число моделей через ICU plural (uk: one/few/many/other), а не «Моделей: N».
3. Ручки линейки с зоной касания ≥ 44px.
4. Фото заменяют силуэты там, где они есть; в линейке нужны вырезки в одном ракурсе.
5. Колонки таблицы зависят от категории; состояние фильтров в URL.
6. Описания показываются на уровне серии, а не повторяются в списках.
