# Критерии готовности

Агент и ревьюер проверяют работу по этому списку. «Готово» = все применимые пункты выполнены и подтверждены выводом команд или скриншотами.

## Глобально (каждый этап)
- G1. `pnpm verify` зелёный. `pnpm e2e` зелёный, если затронуты UI или маршруты.
- G2. Нет ошибок и предупреждений в консоли браузера и в выводе `next build` (hydration, неожиданные динамические маршруты).
- G3. Паритет uk/en и light/dark: нет пропущенных ключей, нет обрезанных и переполненных строк (uk на 15–20% длиннее en).
- G4. Нет строк в компонентах мимо i18n. Нет hex/rgb вне `tokens.css`. Тест-сканер это проверяет.
- G5. Данные не выдуманы. Пустое поле → «—» или скрыто.
- G6. Доступность: axe без нарушений, клавиатура, видимый фокус, контраст ≥ 4.5:1 (текст) и ≥ 3:1 (интерфейс), `prefers-reduced-motion`.
- G7. Производительность: LCP ≤ 2.5s, INP ≤ 200ms, CLS ≤ 0.1 (цель 0) на эмуляции среднего телефона. JS главной ≤ 100 KB gzip (цель).
- G8. Новые зависимости обоснованы записью в `docs/DECISIONS.md`.

## Данные (этап 2)
- D1. 303 модели, 0 дублей slug, 8 категорий; хвостовая пустая строка CSV отброшена.
- D2. Каждый формат из `DATA_CONTRACT.md` покрыт тестом на реальной строке.
- D3. `docs/CATALOG_REPORT.md` содержит счётчики, пустые поля и список `needs-review`.
- D4. Клиентская проекция `catalog.index.json` ≤ 40 KB gzip.

## Визуал (этапы 3–5, 8): оценка 0–5, целевой минимум 4 по каждому пункту
- V1. Верность прототипу и `DESIGN.md`: сетка, отступы, типографика, цвет только из токенов.
- V2. Ритм и читаемость: плотность таблиц, межстрочные интервалы, длинные украинские слова.
- V3. Акцент: красный только на действиях; выбор и диапазон чернилами.
- V4. Состояния: hover, focus, disabled, error, empty, loading — везде, в обеих темах.
- V5. Честный масштаб силуэтов и чертежей (из мм каталога).
- V6. Движение: только по токенам, объяснимо, без сдвигов раскладки.
- V7. Выравнивание: левые края совпадают ±1px, нет горизонтального скролла, подписи линейки под машинами.

## SEO (этап 9)
- S1. Уникальные `title` и `description` на каждой странице обеих локалей; `canonical`; `hreflang` uk/en/x-default.
- S2. `sitemap.xml` и `robots.txt` отражают все публичные страницы; `_styleguide` исключён.
- S3. JSON-LD валиден и не содержит выдуманных полей (нет цен, рейтингов, адресов без источника).

## Безопасность и приватность (этапы 7, 10)
- P1. Серверная валидация, honeypot, лимит запросов, экранирование, нет PII в логах.
- P2. Секреты только в env; `.env.example` актуален; в репозитории секретов нет.
- P3. CSP с nonce, HSTS, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`.
- P4. Сторонние скрипты не грузятся до согласия; аналитика без cookie.
